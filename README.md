# RoofTop Studio Tools

Unity에서 VFX 제작과 에셋 작업을 돕는 에디터 유틸리티 모음입니다.

현재 Unity `2022.3 LTS`에서 사용하고 있으며, 모든 창은 `Tools > RoofTop Studio` 메뉴에서 열 수 있습니다.

---

A collection of editor utilities for VFX creation and asset workflows in Unity.

Currently used with Unity `2022.3 LTS`. All utility windows can be opened from the `Tools > RoofTop Studio` menu.
