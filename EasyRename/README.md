# Easy Rename
![EasyRename](Thumb/EasyRename_Thumb.png)
Project 창에서 선택한 여러 에셋의 이름을 규칙에 맞춰 한 번에 변경하는 도구입니다.

## 주요 기능

- 기본 이름과 시작 번호를 사용한 일괄 이름 변경
- `01`, `02` 형태의 번호 자릿수 정렬
- 기존 이름 유지 후 접미사 추가
- 이름에서 지정한 키워드 제거
- 이름 충돌 확인과 안전한 2단계 변경

## 사용법

1. Project 창에서 이름을 바꿀 에셋을 선택합니다.
2. `Tools > RoofTop Studio > Easy Rename`을 엽니다.
3. 기본 이름, 시작 번호, 접미사 또는 삭제할 키워드를 입력합니다.
4. 미리보기를 확인하고 `선택한 에셋 이름 변경`을 누릅니다.

변경 전에 버전 관리로 프로젝트를 백업하는 것을 권장합니다.

## 출처

원작은 [Bonnate](https://github.com/bonnate)의 도구이며, 번호 자릿수 정렬·접미사·키워드 제거·충돌 방지 기능을 추가했습니다.
